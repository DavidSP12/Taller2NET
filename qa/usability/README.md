# Pruebas de usabilidad

El proyecto sí tiene una UI web real: un dashboard con login, sidebar y secciones dinámicas.

## Qué se automatiza con Selenium

- Login.
- Navegación entre secciones.
- Visualización de tablas y tarjetas.
- Refresco de sección y verificación básica de mensajes.

## Qué se evalúa con checklist

- Responsividad móvil.
- Accesibilidad básica.
- Claridad visual.
- Mensajes de error.
- Consistencia de navegación.
