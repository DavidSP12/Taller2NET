# Checklist heurística de usabilidad

Usar esta lista cuando se requiera evaluación manual o cuando una pantalla no pueda automatizarse.

## Heurísticas evaluadas

1. Visibilidad del estado del sistema.
2. Correspondencia entre el sistema y el mundo real.
3. Control y libertad del usuario.
4. Consistencia y estándares.
5. Prevención de errores.
6. Reconocimiento en lugar de recuerdo.
7. Flexibilidad y eficiencia de uso.
8. Diseño estético y minimalista.
9. Ayuda para reconocer, diagnosticar y recuperarse de errores.
10. Ayuda y documentación.

## Matriz mínima para este proyecto

| Criterio | Qué verificar | Criterio de aceptación |
|---|---|---|
| Login | Validación visual de credenciales | Mensaje claro, sin bloqueos |
| Navegación | Cambio entre 8 secciones | Título y contenido actualizan |
| Tiempos percibidos | Carga de tarjetas y tablas | Feedback visible al cargar |
| Errores | Credenciales inválidas o sesión expirada | Mensaje entendible |
| Accesibilidad | Labels, contraste, foco | Navegación básica posible |
| Consistencia | Botones, badges, tablas | Mismo patrón visual |
