# Pruebas de aceptación

Este paquete define escenarios BDD para los flujos principales del sistema.

## Tecnologías sugeridas

- Cucumber JVM o Cucumber JS.
- Selenium para UI.
- REST Assured para API.

## Cobertura

- Autenticación.
- Consulta del dashboard.
- Gestión de estudiantes.
- Gestión de cursos.
